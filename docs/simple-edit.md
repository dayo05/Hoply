# Simple Edit

## 개발 상태

현재 기능 브랜치의 구현이며 정식 배포본에 포함되지 않았다. 화면 편집과 저장 검사는
Chromium / WebKit에서 통과했고 Swift 검사와 실기기용 arm64 빌드도 통과했다.
별도 양식 5개를 검사하는 과정에서 11쪽짜리 기존 양식의 HWP 저장 후 배치 차이를
발견했다. 따라서 **모든 문서의 서식을 유지하면서 HWP로 저장한다는 조건은 아직 미충족**이다.
검증 실패 파일을 정상 작성본으로 공유하거나 원본을 덮어쓰지 않는다.
이 사례의 조판 경로 수정, 또는 원본을 고정 배경으로 저장할 때의 구조 보존 범위를
확정하기 전에는 릴리스하지 않는다.

## 보존 기준

같은 `@rhwp/core` 0.8.7로 원본과 작성본을 렌더링할 때, 추가한 입력·서명을 제외한
기존 그리기 명령의 내용·위치·순서·clip·상위 transform이 같아야 한다.
숫자의 부동소수점 표현 오차만 0.0001 CSS px 단위로 정규화한다.
쪽 수가 달라지거나 기존 그리기가 바뀌면 정상 저장으로 취급하지 않는다.
이 검사는 다른 한글 프로그램의 렌더링 일치까지 보장하는 검사가 아니다.

원본 문서 모델에 텍스트를 삽입하거나 표의 높이·셀 크기를 변경하는 API를 호출하지 않는다.
화면의 원본 SVG와 별개인 절대 좌표 SVG 레이어에만 입력한다. 페이지를 확대해도
같은 페이지 좌표를 사용한다. 고정 영역을 넘는 텍스트는 적용을 막는다.

## HWP 저장

1. 원본 바이트로 작업용 rhwp 문서를 별도로 연다.
2. 페이지 기준 고정 위치, `InFrontOfText`, 비인라인 개체를 만든다.
   텍스트는 투명 글상자, 서명은 투명 PNG 그림으로 만든다.
3. 새 개체에는 구분자로 끝나는 고유 description을 부여한다. 모델의 control index는 삽입 순서와
   직렬화 과정에서 달라질 수 있으므로 원본/새 개체 식별자로 사용하지 않는다.
4. 작업용 HWP에서 새 개체와 새 리소스만 추출해 원본 CFB 스트림 복사본에 추가한다.
   기존 표·문단·줄 정보는 전체 문서 직렬화 결과로 교체하지 않는다.
5. 원본 리소스 ID가 유지됐는지 확인한다. 변경하지 않은 원본 스트림은 바이트 단위로
   동일함을 검사한다. 알 수 없는 원본 레코드를 제거하지 않는다.
6. CFB의 사용하지 않는 FAT / MiniFAT 항목을 `FREESECT`로 정규화한다.
   SheetJS 기본 패딩의 `ENDOFCHAIN` 값은 엄격한 CFB 파서가 거부한다.
7. 결과 HWP를 다시 열고 모든 쪽의 기존 그리기를 비교한 뒤 바이트를 네이티브로 넘긴다.

원본 HWP는 앱에서도 덮어쓰지 않는다. HWP 3, HWPX, 암호화/배포용 문서의 네이티브
작성본 저장 경로는 이 HWP 5 레코드 경로와 별도로 구현해야 한다.

## 자동 보관과 출력

입력은 Application Support의 SimpleEdit에 JSON으로 원자적으로 저장한다.
문서 원본 SHA-256과 로컬 파일명을 함께 사용해 가져온 사본끼리 입력이 섞이지 않게 한다.
파일명이 바뀌거나 원본 내용이 바뀌면 새 문서로 취급한다. JSON에는 렌더러 버전과
쪽 크기를 보관하며, 다른 렌더링 기준의 입력을 자동으로 덧씌우지 않는다.
입력창에서 아직 적용하지 않은 내용은 저장되지 않는다.

원본 공유는 원본 URL을, HWP 공유는 새 임시 파일을 사용한다. PDF는 각 쪽을 별도로
캡처해 원래 용지 크기와 쪽 수로 합친다. 인쇄도 같은 PDF 경로를 사용한다.
자동 보관은 기기 내부 보관이며 원본 HWP에 임베드되거나 iCloud 동기화되는 기능이 아니다.

## 검증

```bash
npm run build:viewer
npm run ios:typecheck
npm run test:viewer
PLAYWRIGHT_BROWSER=webkit node --experimental-strip-types --test web-viewer/tests/simple-edit.test.mjs
```

`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`와 `PLAYWRIGHT_BROWSERS_PATH`로 설치된 브라우저를
지정할 수 있다. `HOPLY_HWP_TEST_FILE`을 지정하면 개인 문서를 저장소에 복사하지 않고
HWP 왕복 검사를 실행한다. 출력 문서와 개인 문서는 저장소에 포함하지 않는다.

실제 Apple Pencil의 지연·팜 리젝션과 iOS 공유·인쇄는 기기에서 별도로 확인해야 한다.
